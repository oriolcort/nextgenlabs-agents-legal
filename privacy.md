# Privacy policy

Last updated: 22 October 2026

NextGenLabs Agents ("the app") is a personal, single-user application. It is built, run and used
only by its owner, on the owner's own computer, to organise the owner's own information. It has no
other users, and it collects no data about anyone else beyond what appears in the owner's own
mailbox, calendar and documents.

## What data the app accesses

The app asks the owner to authorise access to the owner's own Google accounts and bank accounts:

- **Gmail, read-only** (`gmail.readonly`): it reads the owner's email threads to summarise them and
  to find dates, appointments and tasks. It never sends, replies to, deletes or changes any email.
- **Google Calendar** (read and write): it reads the owner's calendar and adds or updates events
  for appointments and tasks it found. It never invites anyone and never sends notifications.
- **Google Drive**: it reads files the owner puts in an inbox folder (for example saved articles)
  and creates files in a folder it manages.
- **Bank accounts**, read-only, through Enable Banking: balances and transactions, to show the
  owner their own finances. The app never initiates payments.

## How the data is used

The data is used only to give the owner the app's features: a private searchable notebook, a task
list, calendar events and summaries. It is not used for advertising, profiling or any other purpose,
and it is never sold.

To produce summaries, the text of some emails and documents is sent through an API to AI model
providers. It is used only to answer that request. Messages in sensitive categories, such as health
and children's information, are processed only by a language model running on the owner's own
computer and are never sent to an external provider.

## Storage, sharing and retention

- Data is stored only on the owner's own computer and in a private, encrypted repository that only
  the owner can access. Raw emails are not stored; only short summaries, dates and a link back to
  the original message are kept.
- Data is not shared with, sold to or disclosed to any other person or company, except for the AI
  model requests described above. No human other than the owner reads it.
- Data is kept until the owner deletes it. The owner can delete any stored data, or revoke the
  app's access to a Google account at any time at https://myaccount.google.com/permissions.

## Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.

## Contact

To ask a question about this policy or about any data, open an issue in this repository.
